# 🌐 Business Overview & Strategy — BotDigit AI Council

## 1. Executive Summary

**BotDigit AI Council** is an AI Project Intelligence platform. It provides every project with a **persistent, multi-disciplinary AI team** that retains long-term memory, debates challenges using grounded repository and market evidence, maintains an actionable decision history, and automates continuous project maintenance.

Unlike ephemeral chat tools or simple debate scripts, BotDigit AI Council functions as an **AI Operating System for Projects (AI-POS)**, bridging high-level strategic reasoning with low-level code and issue execution.

---

## 2. Core Value Propositions

| Value Proposition | Traditional AI Chat | BotDigit AI Council |
|---|---|---|
| **Context Window** | Ephemeral, lost between sessions | Persistent across months; references past decisions and assumptions |
| **Deliberation Quality** | Single model hallucinating agreement | Multi-agent debate with cross-examination, citations, and red-teaming |
| **Execution** | Code snippets in chat | Direct GitHub integration: automated issue creation, PR reviews, weekly audits |
| **Growth Engine** | Completely closed private silo | Optional public project snapshots that drive organic programmatic SEO |

---

## 3. The Dual-Layer Knowledge Model

Every project maintains a strict boundary between two operational states:

```
┌────────────────────────────────────────────────────────┐
│                   BOTDIGIT PROJECT                     │
├────────────────────────────┬───────────────────────────┤
│  🔒 PRIVATE WORKSPACE      │  🌍 PUBLIC PROJECT PROFILE │
├────────────────────────────┼───────────────────────────┤
│ • Private Repository Code  │ • Verified Public Overview │
│ • Internal Costs & Margins │ • Curated Public Roadmaps  │
│ • Unredacted Transcripts   │ • Sanitized AI Discussions │
│ • Internal Team Discussions│ • Tech Stack Badges       │
│ • Private API Keys & DBs   │ • Public Verified Progress │
└────────────────────────────┴───────────────────────────┘
```

1. **Private Workspace**: Accessible only to authenticated project owners and authorized members. All agents operate on full context (source code, telemetry, financial models).
2. **Public Project Profile (`council.botdigit.site/p/[slug]`)**: Formed strictly via explicit user export. Generates thousands of crawlable, indexable pages showcasing actual architectural decisions, verified development velocity, and public roadmaps.

## 4. Monetization & Business Model

1. **Tier 1: Free Open-Source / Community (Public Focus)**
   - 1 active project.
   - Core 5 agents (Product, Engineering, Security, Growth, Skeptic).
   - Public project profiling enabled (generates platform SEO).
   - Bring-your-own-API-key (BYOK) or standard token limits.

2. **Tier 2: Pro ($29 / project / mo)**
   - Unlimited private projects.
   - All 12 specialized agents (FinTech, Blockchain, SEO, Red Team, UX).
   - Weekly automated Monday AI audits & GitHub webhooks.
   - Persistent decision memory & vector search over full repo history.

3. **Tier 3: Team / Enterprise ($99+ / mo)**
   - Multi-repo workspaces.
   - Custom Agent Persona SDK (custom skills, enterprise compliance rules).
   - SLA guarantees, self-hosted on-premises deployment options.
